Clone do Jogo Termo

Neste tutorial iremos desenvolver um clone simples do jogo Termo utilizando HTML, CSS e JavaScript puro.

O objetivo deste projeto é praticar lógica de programação, manipulação do DOM, eventos e estilização web.

Pré-requisitos

Antes de começar, é recomendado possuir conhecimentos básicos sobre:

  • HTML
  • CSS
  • JavaScript
Este projeto foi desenvolvido sem frameworks externos.

Estrutura do Projeto

A estrutura da pasta será: 

termo-clone/

index.html
style.css
script.js
tutorial.html

Passo 1 - Criando o HTML

O primeiro passo é criar a estrutura principal do jogo.

No arquivo index.html, começaremos criando o título, o tabuleiro e o formulário. 

<div class="game">

  <h1>TERMO</h1>

  <div id="board"></div>

  <form id="form">

    <input
      id="input"
      type="text"
      maxlength="5"
    >

    <button>Enviar</button>

  </form>

</div>

A div com id board será responsável por armazenar as tentativas do jogador.

O formulário será utilizado para enviar palavras.

Passo 2 - Estilizando o Projeto

Agora iremos estilizar o jogo utilizando CSS.

No arquivo style.css, começamos definindo o fundo da página. 

body{
  margin:0;
  background:#121213;
  color:white;
  font-family:Arial;
}

Em seguida criamos os quadrados das letras. 

.tile{
  width:60px;
  height:60px;
  border:2px solid #3a3a3c;
}

Esses quadrados representam cada letra digitada pelo jogador.

Adicionando cores

Agora iremos adicionar as cores utilizadas pelo jogo. 

.correct{
  background:green;
}

.present{
  background:goldenrod;
}

.absent{
  background:gray;
}

Cada classe representa uma situação:

  • Verde → letra correta na posição correta
  • Amarelo → letra existe mas está na posição errada
  • Cinza → letra inexistente

Passo 3 - Criando a lógica do jogo

Agora iremos desenvolver a lógica principal utilizando JavaScript.

Primeiramente criamos a palavra secreta. 

const SECRET = "REACT";

Essa constante armazena a palavra que o jogador deve descobrir.

Capturando elementos

const board = document.getElementById("board");
const form = document.getElementById("form");
const input = document.getElementById("input");

Essas variáveis capturam elementos do HTML.

Escutando o formulário

form.addEventListener("submit", function(e){

  e.preventDefault();

});

O método preventDefault impede que a página recarregue.

Passo 4 - Criando as tentativas

Agora iremos criar as linhas dinamicamente. 

function createRow(word){

  const row = document.createElement("div");

  row.classList.add("row");

}

Essa função cria uma nova linha para cada tentativa.

Criando as letras

const tile = document.createElement("div");

tile.classList.add("tile");

tile.textContent = word[i];

Cada letra será colocada dentro de um quadrado.

Passo 5 - Verificando letras

Agora iremos comparar a palavra digitada com a palavra secreta. 

if(word[i] === SECRET[i]){

  tile.classList.add("correct");

}

Esse trecho verifica se a letra está correta e na posição correta. 

else if(SECRET.includes(word[i])){

  tile.classList.add("present");

}

Aqui verificamos se a letra existe, mas está na posição errada.

Passo 6 - Sistema de vitória

if(guess === SECRET){

  message.textContent = "Você venceu!";

}

Quando o jogador descobre a palavra, uma mensagem de vitória aparece.

Passo 7 - Sistema de derrota

if(attempts >= 6){

  message.textContent = "Você perdeu!";

}

O jogador possui no máximo 6 tentativas.

Resultado Final

Ao finalizar o projeto, teremos um clone funcional do jogo Termo.

O projeto utiliza:

  • Manipulação do DOM
  • Eventos
  • Funções
  • Estruturas condicionais
  • Estilização com CSS

Este projeto permitiu aplicar conceitos fundamentais do desenvolvimento web front-end.
